    任务

      成功条件

      每一条都要在执行结束时被当前界面证实。写明"哪个控件处于什么状态"，就不需要模型也能判定成功。

        步骤

        按名称找控件；名称在界面上重名时，改用 id。可以在"实时界面"里点选控件直接生成步骤。

          输入与限制

          输入

          TYPE 和 SET 只能填这里声明过的值，决策方不能自己编造文字。

            限制

            任务文件 JSON

            和 deskhand run --task 读的是同一种文件。可以直接改，再点"应用 JSON"。

            运行记录

              选择一次运行查看过程和报告。

              执行任务

              不切前台时，只能执行通过无障碍接口完成的动作；需要键盘或鼠标的步骤会被拒绝并记录原因，不会落到你正在用的窗口里。
